# Feishu Quant Competition - Long-Only A-Share Strategy

## Project overview

A concentrated, long-only A-share equity strategy that blends an 8-factor ICIR-weighted
signal (`BaseAlpha`, with partial sector-mean removal) with a purged walk-forward Ridge
regression on the 5-day forward rank. The combined alpha drives a 12-name inverse-vol /
alpha-rank portfolio with sector residualisation, volatility targeting, a breadth gross-up,
and a reactive drawdown breaker, executed sell-at-open under the competition's T+1 rules.
All figures and quantitative results are generated by the accompanying notebooks.

## Notebooks

| Notebook | Purpose |
|---|---|
| `strategy_final.ipynb` | Production strategy. Builds the full daily + LOB factor pipeline, fits the IS-only artifacts (factor weights, frozen sectors, walk-forward Ridge), constructs the portfolio, and reports the in-sample backtest. Exports `figures/fig1_is_equity.png`. |
| `strategy_signal_breakdown_IS.ipynb` | Signal attribution (in-sample). Reuses the identical pipeline and locked simulator but runs the backtest separately on the `BaseAlpha` baseline, the `ridge_5d` sleeve, and the combined Final Alpha, so performance differences are attributable to the signal alone. Exports `figures/fig2_signal_decomposition.png`. |
| `strategy_oos_submission.ipynb` | Out-of-sample evaluation / submission. Applies the same fixed pipeline and hyperparameters to the concatenated in-sample + out-of-sample data and reports OOS results. |

## Environment requirements

- Python 3.12 (tested on 3.12.10)
- Packages listed in `requirements.txt`: `polars`, `numpy`, `pandas`, `matplotlib`,
  `scikit-learn`, and `pyarrow` (required by `polars.DataFrame.to_pandas()`).

### Data files

The notebooks expect the following Parquet files in the working directory (not included
in this repository):

- `daily_data_in_sample.parquet`
- `lob_data_in_sample.parquet`
- `daily_data_release_stage_out_of_sample.parquet`   *(OOS notebook only)*
- `lob_data_release_stage_out_of_sample.parquet`     *(OOS notebook only)*

## Installation

Assuming a clean Python 3.12 environment:

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## Execution order

Each notebook is self-contained and recomputes the full pipeline from the Parquet inputs;
run them top-to-bottom in the following order:

1. `strategy_final.ipynb` - in-sample production run and equity curve.
2. `strategy_signal_breakdown_IS.ipynb` - in-sample signal decomposition.
3. `strategy_oos_submission.ipynb` - out-of-sample evaluation.

Figures are written to a `figures/` directory, which the notebooks create automatically.

## Reproducibility

All figures and quantitative results are generated by the accompanying notebooks. Runs are
deterministic: all stochastic steps (PCA, KMeans) use fixed random seeds, and the pinned
package versions in `requirements.txt` match the environment used to produce the reported
results. Unless otherwise noted, strategy hyperparameters were selected using in-sample
analysis only and remained fixed throughout out-of-sample evaluation. Look-ahead is
controlled at the source via a one-day factor lag, IS-only fitted weights, frozen sectors,
and a purged walk-forward Ridge.
